# dogfood/

This directory is where pickled-spec eats its own dog food: stories,
features, rule sets, and end-to-end tests describing pickled-spec itself.

## What lives here

- `inventory.json` / `inventory.md` — generated by
  `scripts/inventory_functionality.py`; the canonical surface-area map
  used to derive everything else in this directory. Not checked in
  (see `.gitignore`).
- `inventory_schema.json` — contract for `inventory.json`.
- (later) `bdd/stories/*.story.md` — natural-language seeds for the
  `pickled-bdd` drafter.
- (later) `bdd/features/*.feature` — Gherkin features describing
  pickled-spec's own behavior.
- (later) `rulesets/*.yaml` — internal invariants, AI-dev-tool best
  practices, OSS hygiene, and per-package domain rules.
- (later) `tests/` — pytest-bdd end-to-end harness exercising the
  features against the real CLI and MCP server.

## Regenerate the inventory

```bash
python scripts/inventory_functionality.py --verbose
```

Without `--no-mcp` this spawns the umbrella MCP server briefly.

## Why dog food?

If pickled-spec cannot describe and verify itself with its own tools,
the tools aren't ready for anyone else either.
